# Тестовое задание разработчика расширений CMS

## Техническое задание

### Создать новый плагин для WordPress решающий следующие задачи,
1. Добавляет в форму комментария к статье (стандартная форма комментариев) скрытое поле.
2. С помощью JavaScript меняет значение поля на IP адрес посетителя сайта.
3. Анализирует полученные POST массив данных в бекэнд WordPress, и если значение поля не соответствует IP адресу посетителя, то выдает запрет на размещение комментария.


## Условия
1. Плагин разработать в соответствии с требованиями,
https://codex.wordpress.org/Writing_a_Plugin 
https://developer.wordpress.org/coding-standards/wordpress-coding-standards/
2. Use English language only in any interfaces and as code comments.
3. Результат разместить на github.com.
